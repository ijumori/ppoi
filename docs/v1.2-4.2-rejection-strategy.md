# PPOI v1.2 — Guideline 4.2 却下対応戦略

## 却下理由

- **ガイドライン 4.2 - 設計 - 最低限の機能**
- レビュー環境: iPad Air 11インチ（M3）
- レビュー対象: v1.0 (Build 8)
- 要約: 「アプリの有用性は、現在提供されている機能が最小限であるため制限されている」

## 根本原因分析（3エージェントディベートによる）

### 構造的問題
1. **シングルスクリーン構成**: `RootView` → `QuoteView()` のみ。タブバーなし。
2. **機能が隠れている**: お気に入り・アーカイブ・投票は設定画面の奥に埋没。
3. **iPad非対応**: `TARGETED_DEVICE_FAMILY: "1"` でiPad互換モード表示 → 11インチに1行テキスト。

### コンテンツ問題
4. **1日1格言のみ**: ユーザーが能動的にできることがほぼない。
5. **AI解釈なし**: 格言を読んで終わり。深掘りする手段がない。
6. **ブラウジング不可**: 過去の格言やカテゴリ別探索ができない。

### UX問題
7. **課金詐称リスク**: PaywallViewに「お気に入り強化」記載 → コード実装なし。
8. **アニメーション皆無**: 全プロジェクトで7つのみ。ハプティクス0。
9. **アクセシビリティ不足**: `accessibilityLabel` が全プロジェクトで1箇所のみ。
10. **オンボーディング薄い**: 2ページ、テキストのみ、ビジュアルなし。
11. **X直接シェアなし**: UIActivityViewController経由の汎用シェアシートのみ。

## 統合戦略: 3つの柱

### 柱1: 構造改革（MUST）

#### 1-1. タブ化
- **Today**: 今日の格言 + AI解読 + 投票 + シェア
- **Explore**: カテゴリ別格言ブラウジング + 検索 + フィルタ
- **My Page**: 統計 + 実績 + お気に入り + 設定

新規ファイル:
- `PPOI/App/MainTabView.swift`
- `PPOI/Features/Explore/ExploreView.swift`
- `PPOI/Features/Explore/QuoteDetailView.swift`
- `PPOI/Features/Explore/ExploreService.swift`
- `PPOI/Features/MyPage/MyPageView.swift`
- `PPOI/Features/MyPage/StatsSection.swift`
- `PPOI/Features/MyPage/AchievementsView.swift`

変更ファイル:
- `PPOI/App/RootView.swift` — QuoteView() → MainTabView()
- `PPOI/Features/Quote/QuoteView.swift` — ツールバー整理（設定ギア削除）
- `PPOI/Features/Settings/SettingsView.swift` — MyPage配下に移動

#### 1-2. iPad対応
- `project.yml`: 全ターゲット `TARGETED_DEVICE_FAMILY: "1"` → `"1,2"`
- `@Environment(\.horizontalSizeClass)` による適応レイアウト
- iPad: `NavigationSplitView` + サイドバー
- iPhone: 標準 `TabView`
- `UIRequiresFullScreen: true` を `false` に（iPadマルチタスク）

### 柱2: コンテンツ深化（MUST）

#### 2-1. AI解読機能（"この格言を解読する"）
- 日替わり格言の下に「解読する」ボタン
- タップでAI生成の3-4文の解釈を展開表示
- Firestoreの `quotes/{date}` に `interpretation` フィールド追加
- サーバーサイドで格言と同時に生成（Cloud Functions）

新規ファイル:
- `PPOI/Features/Quote/InterpretationView.swift`

変更ファイル:
- `PPOI/Core/Data/Models/Quote.swift` — `interpretation: String?` 追加
- `PPOI/Features/Quote/QuoteView.swift` — 解読セクション追加
- `PPOI/Core/Data/Repositories/FirestoreQuoteRepository.swift` — interpretation読み取り

#### 2-2. カテゴリ別探索（Exploreタブ）
- カテゴリ: 人生/仕事/恋愛/笑い/哲学/孤独 等
- 各カテゴリに10-20の格言（週次ローテーション）
- Firestore: `categoryQuotes/{categoryId}/quotes/{autoId}`
- スワイプ式カード閲覧

新規ファイル:
- `PPOI/Core/Data/Models/QuoteCategory.swift`
- `PPOI/Features/Explore/CategoryDetailView.swift`

#### 2-3. 一句日記（パーソナルジャーナル）
- 日替わり格言に対する個人的な振り返り（200文字以内）
- ローカル保存（UserDefaults or JSON file）
- アーカイブ・お気に入りに表示

新規ファイル:
- `PPOI/Features/Journal/JournalInputView.swift`
- `PPOI/Features/Journal/JournalListView.swift`

変更ファイル:
- `PPOI/Core/Persistence/UserDefaultsStore.swift` — reflections辞書追加
- `PPOI/Features/Archive/ArchiveView.swift` — ジャーナル表示

### 柱3: UX磨き込み（MUST）

#### 3-1. オンボーディング刷新
- 2ページ → 4ページに拡張
- P1: AI格言コンセプト紹介（アニメーション付き格言デモ）
- P2: シェアカードプレビュー（Xポストイメージ）
- P3: テーマ選択プレビュー（ライブスワップ）
- P4: 通知許可（ストリーク説明付き）
- ページインジケーター追加
- 各ページで順次アニメーション

#### 3-2. 格言リビールアニメーション
- 単純な opacity fade → ブラー→シャープ or タイプライター効果
- `.sensoryFeedback(.impact)` でハプティクス追加
- お気に入りハートのバウンスアニメーション
- 投票ボタンのスケールアニメーション
- テーマ切替のクロスディゾルブ

#### 3-3. 課金フロー修正
- **「お気に入り強化」を実装 or 削除**（現状: 虚偽表示）
  - 実装案: 無料ユーザーお気に入り上限10件、プレミアム無制限
- **プレミアム専用テーマ2-3種追加**（「全テーマ解放」を実質化）
- **アーカイブ全件アクセスをPaywall特典に追記**
- **購入完了時のセレブレーション画面追加**（コンフェッティ等）
- プレミアム専用フォント追加

#### 3-4. X（Twitter）直接シェア
- `twitter://post?message=...` URLスキームで直接投稿
- フォールバック: `https://x.com/intent/tweet?text=...`
- 最終フォールバック: UIActivityViewController
- シェアテキストに格言テキスト（短縮）+ ハッシュタグ + App Store URL

新規ファイル:
- `PPOI/Features/Share/XShareService.swift`

#### 3-5. アクセシビリティ
- Dynamic Type対応（ハードコード `.system(size:)` → `@ScaledMetric`）
- 全インタラクティブ要素に `accessibilityLabel` / `accessibilityHint`
- `@Environment(\.accessibilityReduceMotion)` でアニメーション制御
- VoiceOver読み上げ順序の最適化

## 課金後のフロー（修正版）

### 購入前（無料ユーザー）
```
今日の格言（1日1件）
├── シェア → UIActivityViewController / X直接シェア
├── お気に入り保存（上限10件）
├── 投票（リアクション4種）
├── Explore → 過去3日分のみ閲覧可
├── バナー広告表示
└── シェア後インタースティシャル広告
```

```

├── シェア → 同上（広告なし）
├── お気に入り保存（無制限）
├── 投票（同上）
├── Explore → 全期間閲覧可 + カテゴリ別ブラウジング
├── AI解読（制限なし）
├── 広告完全除去
├── プレミアム専用テーマ3種解放
├── プレミアム専用フォント2種解放
├── ストリーク復活（月1回）
└── 購入完了時セレブレーションアニメーション
```

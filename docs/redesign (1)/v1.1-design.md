## W1. 創作明示

### 目的
- AI生成の創作であり、実在の名言ではないことを示し、本物誤認・引用クレームを防ぐ。

### 配置
| 箇所 | 表現 | 既存ファイル |

| ホーム | 格言下に控えめなキャプション「AIが紡ぐ創作格言」 | `Features/Quote/QuoteView.swift` |

- プレミア感を損なわないトーン（小さめ・低コントラストの補助テキスト）。テーマカラートークンに従う（`DesignSystem/AppTheme.swift`）。

## W2. お気に入り保存（ローカル）

### 方針
- **ローカルのみ**（サーバー非同期）。当日限定の世界観を壊さないため、保存できるのは「自分が見た日の格言」に限る。
- 過去全アーカイブの自由閲覧は引き続き Won't。お気に入りは「自分が保存した分だけ」の小さな振り返りリスト。

### データ
`UserDefaultsStore`（`Core/Persistence/UserDefaultsStore.swift`）にキーを追加。`Quote` は `Codable` 済みなので配列を JSON 化して保存。

```swift
// UserDefaultsStore に追加するイメージ
private enum Key {
    // ...既存...
    static let favorites = "favorites"
}

var favorites: [Quote] {
    get {
        guard let data = defaults.data(forKey: Key.favorites),
              let list = try? JSONDecoder().decode([Quote].self, from: data)
        else { return [] }
        return list
    }
    set {
        let data = try? JSONEncoder().encode(newValue)
        defaults.set(data, forKey: Key.favorites)
    }
}

func toggleFavorite(_ quote: Quote) {
    var list = favorites
    if let idx = list.firstIndex(where: { $0.id == quote.id }) {
        list.remove(at: idx)
    } else {
        list.insert(quote, at: 0)
    }
    favorites = list
}

func isFavorite(_ quote: Quote) -> Bool {
    favorites.contains { $0.id == quote.id }
}
```

### UI
- ホーム（`QuoteView`）にハート（SF Symbols `heart` / `heart.fill`）トグルを追加。`QuoteViewModel` にお気に入り状態を持たせる。
- お気に入り一覧画面は v1.1 では**設定からのシンプルなリスト**（タブバーは増やさない）。各行：日付 + 格言抜粋。タップで共有プレビューへ再利用可。

### 留意
- 件数上限（例: 100件）を設けて UserDefaults 肥大化を防ぐ。
- セキュリティ：`SecureQuoteCache` と同様、機微情報ではないため平文 UserDefaults で可。ただし `InputSanitizer` 経由の考察テキストは保存対象外（格言本文のみ保存）。

## W3. ストリーク表示

### 定義
- **連続閲覧日数** = 「アプリで今日の格言を表示した日」が JST 日付で連続した数。
- 1日でも空くとリセット（=1から再開）。共有や保存は条件にしない（閲覧のみで成立、ハードルを下げる）。

### データ
`UserDefaultsStore` に2キー追加。

```swift
static let currentStreak = "currentStreak"
static let lastSeenDate = "lastSeenDate"   // yyyy-MM-dd
```

### ロジック（格言表示成功時に1回実行）
```text
today = JST今日
last  = lastSeenDate
if last == today        -> 何もしない（同日再表示）
else if last == 昨日     -> currentStreak += 1
else                    -> currentStreak = 1   // 初回 or 途切れ
lastSeenDate = today
```

- 実行箇所: `QuoteViewModel.loadQuote` で `quote` 取得成功後（フォールバック表示時は加算しない方針も検討、初期は加算で簡素化）。

### UI
- ホーム上部に控えめに「🔥 N日連続」相当（テーマに合わせアイコン/文言調整）。
- 0/1日目は非表示 or 「今日から」。誇張せず、習慣の後押し程度に留める。

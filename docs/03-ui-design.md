## §1 「考察してシェアする」操作フロー

**P3-Q1**: ボタン押下後のフロー

**回答**: **C + 入力時プレビュー**

```
「考察してシェアする」タップ
    ↓
考察入力シート（任意）
    ├─ 入力なし → スキップ → 画像生成 → 𝕏共有（プレビューなし）
    └─ 入力あり → プレビュー → 𝕏共有
    ↓
共有後インタースティシャル広告
```

### 考察入力シート

| 要素 | 内容 |
|------|------|
| プレースホルダ | この格言、あなたはどう読んだ？ |
| ボタン（入力なし） | スキップして共有 |
| ボタン（入力あり） | プレビュー |

### プレビュー画面（入力時のみ）

- 共有カード画像のプレビュー
- 投稿テキストプレビュー（`私の考察：{入力}` + `#っぽい格言`）
- CTA: 𝕏で共有

**確定**: ✅

# 要件定義書 — っぽい格言

> 一問一答形式で記入していく。回答が確定したら ✅ に更新する。

## §1 アプリの目的・一言説明

**Q1**: このアプリを一言で説明すると？

**回答**:

AIが生成する「それっぽい」日本語の格言と、既存名言を混ぜたオリジナルっぽい格言を、**日付ごとに1つ**届ける娯楽アプリ。

- **全ユーザー同期**: ダウンロード日に関係なく、同じ日付なら全員が同じ格言を見る
- **共有**: 「考察してシェアする」— 各自の解釈を𝕏に投稿。大喜利化も、本当の格言になる可能性も
- **タイポグラフィ**:
  - **通常UI**（ボタン、設定、オンボード本文等）: **システムフォント**（SF Pro）
  - **格言本文のみ** A/Bテスト: カチッと（`.serif`） vs ゆるめ（`.default`）— いずれもシステムフォント
- **テーマ**: ビジュアル3案（和風 / ポップ / ダーク）をユーザーが設定で選択可能

**確定**: ✅

## §3 コア機能

**Q3**: MVP の Must / Should / Won't は？

**回答（確定分）**:
- **過去の格言は見られない** — 当日のみ閲覧可能
- **プレミア感** — 「今日だけ見られる」限定体験を核にする

### Must（MVPに必須）
- 今日の格言を1件表示（日付ベース・全員同じ）
- **当日のみ閲覧可**（過去分のアーカイブ・カレンダーはなし）
- 𝕏 **「考察してシェアする」**（**画像共有メイン** + 短い考察テキスト）
- **テーマ選択**（和風ミニマル / モダン・ポップ / ダーク・プレミア）
- プッシュ通知（毎日「今日の格言」）

### Should（あれば良い）
- お気に入り保存
- 字体 A/Bテスト（カチッと vs ゆるめ）

### Won't（今回やらない）
- 過去の格言を見返す機能
- ユーザーが格言を生成する機能
- コメント・いいね等のSNS機能
- 課金（サブスク・買い切り）

**確定**: ✅

## §4 格言の生成方式

**Q4**: 毎日の格言はどう作るか？

**回答**: **A. サーバー側でAI生成**

- 毎日（例: 0時 JST）にバックエンドが AI で1件生成
- 生成結果を全ユーザーに同期配信
- アプリはサーバーから「今日の格言」を取得する

**確定**: ✅

## §5 画面一覧

**Q5**: MVP に必要な画面は？

**回答**: 下記3画面で確定

| 画面名 | 説明 | 優先度 |
|--------|------|--------|
| 今日の格言（ホーム） | 当日の格言1件表示、**「考察してシェアする」**ボタン | Must |
| 設定 | 通知 ON/OFF・時刻、**テーマ3択**、字体 A/B | Must |
| 初回オンボーディング | **考察シェアの説明** + 通知許可案内（2画面） | Must |

- タブバーなし（最小構成）
- 過去閲覧画面なし

**確定**: ✅

## §6 収益化・課金

**Q6**: MVP の収益化方針は？

**回答**: **C. 広告あり（カスタム）**

- **バナー**: 画面下部に常時表示
- **インタースティシャル**: **𝕏共有後**に全画面表示（起動時は表示しない）
- 課金（サブスク・買い切り）は今回なし

**確定**: ✅

## §7 非機能要件

**Q7**: 非機能要件は？

**回答**:

| 項目 | 内容 |
|------|------|
| 言語 | 日本語のみ |
| 日付の基準 | JST（日本時間 0:00 で切り替え） |
| オフライン | 当日分はキャッシュ表示可（取得済みなら電波なしでも閲覧可） |
| 最小 iOS | iOS 17+ |
| 対応端末 | iPhone のみ（iPad 非対応） |

**確定**: ✅

# AdMob ポリシー準拠 — っぽい格言

> 無効トラフィック（Invalid Traffic）による **アカウント停止を防ぐ** ための設計・運用ルール

## ⚠️ 最重要ルール

| 禁止 | 理由 |
|------|------|
| **本番広告の自己クリック** | アカウント停止の最大原因 |
| **テスト中の本番ユニット使用** | 開発者のクリックが無効トラフィックと判定される |
| **家族・友人への「広告タップ頼み」** | 人为的クリック増加 |
| **インセンティブ付きクリック** | ポリシー違反 |
| **広告をコンテンツと誤認させる配置** | 偶発クリック誘発 |

参考: [無効トラフィックの防止](https://support.google.com/admob/answer/3342099) / [テスト広告](https://developers.google.com/admob/ios/test-ads)

---

## 現状の実装（検証結果）

### ✅ 安全な設計

| 項目 | 状態 | 実装 |
|------|------|------|
| DEBUG でテストユニット強制 | ✅ | `AdMobConfig.usesTestAdUnits` |
| 公式デモ広告 ID 使用 | ✅ | `ca-app-pub-3940256099942544/...` |
| シミュレータをテストデバイス登録 | ✅ | `GADSimulatorID` |
| DEBUG 警告ラベル | ✅ | バナー上「TEST AD — クリック禁止」 |
| インタースティシャルは共有後のみ | ✅ | 起動時表示なし（偶発クリック防止） |
| バナーは画面下部固定 | ✅ | コンテンツと分離 |
| Release のみ本番 ID | ✅ | `#if DEBUG` 分岐 |

### ⚠️ 運用上の注意（要遵守）

| 項目 | 対応 |
|------|------|
| **TestFlight / 実機 DEBUG** | テスト広告のみ。本番広告をクリックしない |
| **Release ビルドの自己テスト** | AdMob Console でテストデバイス登録してから |
| **AdSense** | 本アプリは **AdMob のみ**（Web AdSense とは別アカウント） |

## ビルド別の広告 ID

| ビルド | バナー / インタースティシャル | 自己クリック |
|--------|-------------------------------|-------------|
| **Debug（Xcode Run）** | Google デモ ID（テスト） | デモ広告は動作確認のみ。連打しない |
| **Release（TestFlight / App Store）** | 本番 ID（AdMobConfig.plist） | **絶対に自分でクリックしない** |

## 開発者チェックリスト

### 日常開発（Debug）

- [ ] Xcode から Run → バナーに **「TEST AD」** ラベルが出る
- [ ] 広告は **動作確認のみ**（表示されるか）— クリックしない
- [ ] 本番 ID で Debug ビルドしない（コードでブロック済み）

### TestFlight / リリース前

- [ ] [AdMob Console](https://apps.admob.com/) → 設定 → **テストデバイス** に端末を追加
- [ ] テストデバイスでは「Test Ad」ラベル付き広告が表示される
- [ ] **自分・開発メンバーは本番広告をクリックしない**
- [ ] 広告表示は実ユーザーの自然な利用に任せる

### リリース後

- [ ] AdMob Console で **無効トラフィック** アラートを定期確認
- [ ] クリック率（CTR）が異常に高い場合は実装を見直す
- [ ] ポリシーセンターのメールを確認

## 広告配置ポリシー（本アプリ）

| 広告 | 配置 | ポリシー適合 |
|------|------|-------------|
| バナー | ホーム最下部 | ✅ コンテンツと明確に分離 |
| インタースティシャル | 𝕏共有完了後 | ✅ ユーザーアクション後（偶発表示なし） |

### やっていないこと（良い）

- ❌ 起動直後のインタースティシャル
- ❌ 格言テキストの上に広告重ね
- ❌ 広告とボタンの近接配置（誤タップ誘発）
- ❌ 「広告をタップして続行」

## AdSense との関係

| サービス | 本アプリ |
|----------|----------|
| **AdMob** | ✅ 使用中（モバイルアプリ） |
| **AdSense** | ❌ 未使用（Webサイト用） |

AdMob アカウント停止は AdSense にも影響する場合があります。AdMob ルールを最優先してください。

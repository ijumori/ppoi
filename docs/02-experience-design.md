## §4 ユーザージャーニー

```
通知（12:00）→ アプリ起動 → 今日の格言を読む
    → 意味を考える（考察）
    → 「考察してシェアする」タップ
    → 考察テキスト入力（任意）
    → **共有画像を自動生成**（格言＋考察＋日付＋#っぽい格言）
    → 𝕏 に画像 + 短いテキストで投稿（文字数節約）
    → 共有後インタースティシャル広告
```

**コア体験**: 「っぽい」から「各自の解釈」へ。正解はない。

## §5 「考察してシェアする」

**P2-Q5**: 共有ボタンと体験の核

**回答**:

- ボタン文言: **「考察してシェアする」**（「シェアする」から変更）
- **理由**: 格言は「っぽい」もの。正解はなく、読者それぞれの解釈が価値になる
- **期待する展開**:
  - ユーザーが自分の解釈・感想を𝕏に投稿
  - 大喜利・議論に発展する可能性
  - 解釈の積み重ねで「本当の格言」になる可能性も
- **共有形式**: **画像メイン**（文字数節約・バズ向け）
  - 画像内: 格言、日付、ユーザー考察（入力時）、#っぽい格言、アプリ名
  - 投稿テキスト: 短い考察のみ（画像に格言があるため省スペース）
- **共有テンプレート（案）**:
  ```
  【画像】← 格言・考察・日付を描画

  【投稿テキスト】
  私の考察：{ユーザー入力}
  #っぽい格言
  ```

**確定**: ✅
